## 1. 概述

本文档定义了微存(Wecun)从纯免费工具向Freemium模式转型的技术方案。采用"免费基础功能 + 一次性付费解锁高级功能"的模式，符合国内用户习惯，技术实现简单，维护成本可控。

### 1.1 目标

- 为免费用户提供基本微博归档能力
- 为付费用户提供高级导出和分析功能
- 建立可持续的商业化路径
- 保持现有用户体验不受影响

### 1.2 核心决策

**收费模式**: Freemium + 永久授权
**定价策略**: 早鸟价¥49，正式价¥68
**授权验证**: 本地许可证验证，绑定设备
**开发周期**: 8周

### 2.2 付费功能（新增）

#### A. 精美PDF电子书导出

**用户价值**: 将微博内容导出为可打印、可分享的书籍格式

**功能特性**:
- 自动生成封面（包含博主头像、昵称、简介、微博数量）
- 交互式目录（页码对应，可点击跳转）
- 书籍化排版（章节标题、页眉页脚、分页符）
- 两种主题：现代简约 / 经典书籍风格
- CJK字体支持（思源宋体/黑体）

**技术实现**:
- 使用 `printpdf` crate 生成PDF
- 从 `src-tauri/assets/fonts/` 加载中文字体
- 封面模板：Rust 模板引擎（Tera 或 Handlebars）
- 目录生成：扫描微博数据，自动构建目录结构

#### B. 博主个人画像分析

**用户价值**: 深度了解博主的内容特征和风格

**功能特性**:
- **基础统计**: 发博频率、时间分布、字数统计
- **内容分析**: 高频词云（Top 50）、话题标签统计、@提及分析
- **情感分析**: 正负面情绪比例、情绪趋势图
- **影响力指标**: 转发/评论/点赞比率

**技术实现**:
- 中文分词：`jieba-rs` crate
- 词频统计：Rust HashMap 统计
- 情感分析：基于词典的简单判断（BosonNLP 情感词典）
- 数据可视化：生成HTML图表（Chart.js）

#### C. OpenClaw兼容导出

**用户价值**: 导出的格式可直接用于AI代理训练

**功能特性**:
- **identity.md**: 博主基本信息、风格特征、写作习惯
- **soul.md**: 内容主题、价值观倾向、语言模式

## 4. 授权系统设计

### 4.1 授权码格式

**格式**: `XXXXX-XXXXX-XXXXX-XXXXX` (Base32编码)

**生成算法**:
```rust
fn generate_license_code(email: &str, fingerprint: &str) -> String {
    let input = format!("{}:{}", email, fingerprint);
    let hash = sha256(input.as_bytes());
    let encoded = base32_encode(hash);
    format!("{}-{}-{}-{}",
        &encoded[0..5],
        &encoded[5..10],
        &encoded[10..15],
        &encoded[15..20]
    )
}
```

**机器指纹**:
```rust
fn get_machine_fingerprint() -> Result<String> {
    let cpu_id = get_cpu_id()?;
    let mac_address = get_primary_mac()?;
    let motherboard = get_motherboard_serial()?;
    Ok(format!("{}:{}:{}", cpu_id, mac_address, motherboard))
}
```

### 4.2 验证流程

```
1. 用户输入授权码
   ↓
2. 应用获取本地机器指纹
   ↓
3. 用相同算法验证授权码
   ↓
4. 验证通过？
   ├─ 是 → 写入授权状态到配置文件
   │         { email, code, devices, activated_at }
   └─ 否 → 显示"授权码无效"提示
```

### 4.3 设备绑定策略

- **默认**: 绑定2台设备
- **扩展**: 支持重新激活（解绑旧设备）
- **存储**: 本地配置文件 `license.json`

**license.json示例**:
```json
{
  "email": "user@example.com",
  "license_code": "ABC12-DEF34-GHI56-JKL78",
  "devices": [
    {
      "fingerprint": "hash1",
      "device_name": "MacBook Pro",
      "activated_at": "2026-04-08T10:00:00Z"
    }
  ],
  "activated_at": "2026-04-08T10:00:00Z"
}
```

### 4.4 防破解措施

1. **定期验证**: 每月静默验证一次
2. **黑名单机制**: 服务器维护被破解的授权码
3. **混淆处理**: 验证逻辑代码混淆
4. **服务器同步**: 可选的云端验证（防破解加强）

| 风险 | 概率 | 影响 | 缓解措施 |

| PDF生成质量不达标 | 中 | 高 | 多次测试不同字体和排版方案，提供预览功能 |

| 字体加载失败 | 低 | 低 | 多种字体备选，降级方案 |
